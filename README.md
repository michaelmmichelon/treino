# Treino

App de treino para celular (**iPhone e Android**): fichas de treino, registro de séries, cronômetro de descanso,
evolução de carga, recordes, peso e medidas, e um guia com fotos de 60 exercícios.

**Abrir o app:** https://michaelmmichelon.github.io/treino/

É um PWA (aplicativo web instalável): ganha ícone na tela inicial, abre em tela cheia e funciona sem internet.
Os dados ficam salvos só no próprio aparelho.

## Instalar
**iPhone:** abra o endereço no **Safari** → **Compartilhar** → **Adicionar à Tela de Início**.

**Android:** abra o endereço no **Chrome** → menu **⋮** → **Instalar app** (ou **Adicionar à tela inicial**).

## Sobre este repositório
Gerado a partir do projeto 16-app-treino. Não edite aqui: rode `npm.cmd run publicar` no projeto.

Fotos dos exercícios: [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (domínio público).
